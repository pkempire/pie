## The reframe

The frontier question is no longer "how do I retrieve facts" — it's **how does an agent turn a
corpus/experience into expertise it can use cheaply later**. Li calls this *machine studying*
and defines expertise as efficiency: accuracy per unit of inference compute, measured across
budgets. His findings: continual pre-training and synthetic-QA fine-tuning both failed;
**the only method that worked was the cheatsheet — a studied, compressed notes artifact**
(+48% expertise on DSPy tasks). That is *exactly* the artifact a memory consolidator produces.
Letta argues the same from the systems side: agents learn in token space (readable, portable,
debuggable), with sleep-time compute doing the studying, and distillation-to-weights later.

So: mempol's consolidator work, the eval matrix, the reward machinery, and the tinker training
loops are not "memory system plumbing" — they are ~80% of an **RL/optimization environment for
studying agents**. That's the asset.

## The build: a studying-agent environment + the agents trained in it

**StudyGym (working name).** An environment where an agent gets (corpus, study budget) →
produces a memory artifact (cheatsheet/notes/KB) → is graded on downstream tasks at multiple
inference budgets (Li's expertise curve = the reward). Corpora: this repo (ledger ingestion
already works), DSPy-style fast-moving OSS repos (StudyBench is public — adopt, don't rebuild),
personal exports (PIE data). Baselines: existing strategies registry (turn-RAG, timeline
synthesis, continuity teacher). Optimizers: GEPA on the studying prompt (cheap, verified-open
niche), then GRPO via tinker-cookbook (loops exist), on-policy distillation from
continuity-teacher traces (sft_warmup.jsonl exists).

Why this instead of a benchmark: an environment IS the benchmark plus the training loop plus
the artifact people can use. It ships on Prime Intellect's hub (distribution + possible bounty
money), it trains agents (research result), and its output artifact (the studied expertise
pack) is the product seed.

## The product wedge (6-month horizon)

**Agents that get measurably better at YOUR repo/domain every week.** Sleep-time studying for
coding agents: nightly job reads the repo + session transcripts, updates a reviewable expertise
pack (MEMORY.md / cheatsheet PR you approve). Cursor removed its memory feature; Claude Code
auto-memory saves junk; Devin's KB is manual — "automatic learning with review" is the loudest
unsolved complaint in coding-agent memory. Applied Compute proves enterprises pay for
"RL on your data" at nine figures; the token-space version (studied context packs, no weight
training) is deliverable by one person and portable across models — Letta's own argument.

Proactivity/synthesis comes from the same loop, not a separate system: the studying pass that
compresses also emits deltas — contradictions with past decisions, connections, "this changed
since last week." That's PIE reborn as an output of studying, not a KG to query.

# Amory

## Quick read

Amazon's memory architecture with explicit episodic memory + semantic memory split, retrieved coherently (not just top-k). 87.7% on LoCoMo, only 1.6pp above their own full-context baseline of 86.1%. The CoALA framing is operationalized.

## Numbers

- Amory (EM+SM): **87.7%**
- Full-context: 86.1%
- Mem0: 59.9%

## Pattern

The marginal-over-full-context number echoes [[2512.12818-hindsight|Hindsight]]. When the base model is good and context fits, memory architecture sophistication shows ~1-3pp. The "memory matters" pitch becomes much weaker at frontier model scale.

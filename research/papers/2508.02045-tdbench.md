# TDBench — Temporal Databases for Factual Time-Sensitive QA

## Quick read

Generates time-sensitive QA pairs via SQL joins over a temporal database and scores **time accuracy separately from answer accuracy**.

## Why it matters to us

The metric-design reference for any "is the stored fact still current / what was true when" evaluation: separating temporal correctness from answer correctness is exactly what LoCoMo/LongMemEval fail to do.

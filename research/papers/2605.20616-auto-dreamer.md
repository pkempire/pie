# Auto-Dreamer: Learning Offline Memory Consolidation for Language Agents

## Quick read

Auto-Dreamer trains a GRPO consolidator that runs *offline* over a typed memory bank built by a fast online writer. Given a working region (recent writes + retrieved entries from the last k sessions), the consolidator does bounded tool-use to inspect entries and source trajectories, then emits a compact replacement set. Trained on ScienceWorld alone; held-out generalization to ALFWorld and WebArena. Memory bank is ~12× smaller than the strongest baseline, with +7pp success rate.

## Why it matters to us

This is the paper we'd compete with. They built the consolidator-with-outcome-reward architecture we discussed. Direct implication: any "learned consolidation" pitch we make must differentiate from Auto-Dreamer on either the training method (GEPA instead of GRPO?), the substrate (different schema?), or the application domain (conversational vs agent trajectories).

The GEPA-vs-GRPO ablation is the cleanest delta: their GRPO setup used 200 steps × group size 8 × batch 16 = ~25,600 rollouts on 8x H100. GEPA claims 35× fewer rollouts at comparable/better quality. If we can match their numbers with ~$200 of GEPA compute instead of 8x H100 time, that's a real contribution.

## Method in one paragraph

Memory bank B is a set of typed textual entries, each with name, body, provenance links, and type (semantic = factual, procedural = how-to with steps). The writer emits INSERT_SEMANTIC and INSERT_PROCEDURAL ops online. The consolidator runs offline on a working region R = recent writes + entries the task agent retrieved during the last k sessions. It receives R plus the provenance-linked source trajectories T_R. It calls one of 4 tools per turn (search_memory(query, k=5), check_memory(ids), get_source_trace(id), synthesize(source_ids, type, name, summary, [details|steps])) or terminate(). After termination, the synthesized set S replaces R: B* = (B - R) ∪ S. Training uses GRPO with reward r_g = U_V(S_g) + α·r_cf(S_g; V), where U_V is end-to-end task success on validation set V, and r_cf is a counterfactual term that subtracts expected utility under random masking.

## Results in numbers

ScienceWorld continual deployment (Table 1):
- Auto-Dreamer: 41.1% SR, 6,947 tokens, AUC 0.411
- UMEM (strongest baseline): 34.1% SR, 80,918 tokens
- ReasoningBank: 30.9% SR, 155,117 tokens
- → +7pp, ~12× less memory

ALFWorld held-out (no retraining):
- Auto-Dreamer: 60.2%, 10,954 tokens, AUC 0.585
- UMEM: 58.4%, 62,947 tokens (~6× more)
- Mem-α: 57.4%, 125,635 tokens (~12× more)

WebArena held-out:
- Auto-Dreamer: 52.3%, 927 tokens
- AWM: 52.0%, 890 tokens
- LightMem: 52.0%, 370,874 tokens

Fixed-bank Panel B (separate setup):
- ALFWorld: Auto-Dreamer 72.7% / 634 tokens vs ExpeL 70.1%
- ScienceWorld: Auto-Dreamer 44.3% / 539 tokens vs Mem0 42.0%

Ablations:
- GRPO over untrained consolidator: +9.7pp on ScienceWorld, +5.7pp on WebArena, +1.0pp on ALFWorld
- Without counterfactual reward: bank grows unboundedly
- Cadence k ablation: ScienceWorld peaks at k=10; ALFWorld robust k=5-8
- Fan-in distribution peaks at 5 source entries per synthesized entry

## What they don't do

- Multimodal (only text-based envs)
- Conversational memory (no LoCoMo / LongMemEval)
- Writer/schema variation (consolidator tied to fixed writer)
- Looser retrieval budgets (their +7pp depends on top-K=3 with token cap)
- Statistical variance (single seeds, no error bars)
- Code is not released as of 2026-05-25

## Open questions / followups

- What's the GRPO compute cost in $? They report 8x H100 + 200 steps but no wall time.
- Does the consolidator quality plateau with more rollouts? GEPA's claim is 35× sample-efficiency win — does that scale?
- The "counterfactual reward" sounds adjacent to our per-op counterfactual idea but different: theirs masks fractions of S; ours leaves out individual ops. Worth comparing.
- LoCoMo / LongMemEval setting — would Auto-Dreamer transfer? TiMem is the conversational SOTA in that direction; comparison is open.

## Abstract (verbatim, for reference)

> Language agents increasingly operate over streams of related tasks, yet existing memory systems struggle to convert accumulated experience into reusable knowledge. Retrieval-augmented and structured memory methods record per-session observations effectively, but often couple acquisition and consolidation into a single online process, leaving the agent without a global view across sessions to discover recurring patterns, abstract shared procedures, or prune redundant entries. Inspired by complementary learning systems theory, we propose Auto-Dreamer, a learned offline consolidator for language-agent memory.

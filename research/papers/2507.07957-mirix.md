# MIRIX

## Quick read

Multi-agent memory architecture: instead of one big memory module, multiple specialized agents handle retrieval, consolidation, conflict resolution. **85.38% on LoCoMo ✅ abstract-verified** (abstract says "85.4%", leaderboard table 85.38, consistent rounding). From the MIRIX team. Closest published work to combining [[multi-agent-delegation|multi-agent orchestration]] with memory.

The verified abstract sentence: *"On LOCOMO, a long-form conversation benchmark with single-modal textual input, MIRIX attains state-of-the-art performance of 85.4%, far surpassing existing baselines."*

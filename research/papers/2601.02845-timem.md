# TiMem: Temporal-Hierarchical Memory Consolidation for Long-Horizon Conversational Agents

## Quick read

TiMem is a 5-level temporal hierarchy — fragments (L1) consolidate into session summaries (L2), then daily (L3), weekly (L4), high-level (L5) — with prompt-only consolidation between levels. Time-triggered cron schedule simulates "midnight backfill." No fine-tuning; just careful prompts. ACL 2026 Findings.

**Correction note (2026-05-26):** Initially logged as LoCoMo SOTA at 75.30%. That was wrong. Current LoCoMo SOTA is [[2601.02163-evermemos|EverMemOS]] at 93.05% per paper_leaderboard verification. TiMem sits mid-pack — useful as a prompt-only reference, not the bar.

## Why it matters to us

Three big things:

1. **This is the LoCoMo number to beat.** PIE 63% → TiMem 75% is a 12-point gap. If we want a conversational-memory contribution, TiMem is the floor.
2. **It's prompt-only.** No fine-tuning means GEPA can directly evolve their prompts. Auto-Dreamer requires GRPO; TiMem doesn't. We could GEPA-optimize TiMem's L1-L5 prompts as a direct ablation.
3. **Code is real and they shipped.** github.com/TiMEM-AI/timem, full Python implementation, LoCoMo reproduction scripts at `experiments/datasets/locomo/`. Already cloned to `external/timem/`.

## Method in one paragraph

Five-level Temporal Memory Tree. Each conversation turn arrives at L1 (fragment summary, third-person paraphrase of a dialogue window). L1 fragments aggregate via prompt into L2 (session summary, 150-200 words, chronological). L2 sessions aggregate into L3 (daily summary), then L4 (weekly), then L5 (high-level persona). Triggers are time-based: a CatchUpDetector simulates a 2 AM cron that runs backfills. Retrieval is 3-stage (rough filter → semantic filter → reranker) configurable per dataset. The "consolidator" is just the L1-L5 prompts — no learned model. All LLM calls (generation, retrieval, QA, judge) use gpt-4o-mini in their published config.

## Results in numbers

- LoCoMo: 75.30% (vs our PIE 63%, Mem0 ~27%, Mastra-OM not directly comparable)
- LongMemEval-S: 76.88%
- 52.20% reduction in recalled memory length on LoCoMo
- Manifold analysis shows clear persona separation on LoCoMo, reduced dispersion on LongMemEval-S

## What they don't do

- No learned consolidator (just prompts)
- No agent-trajectory memory (only conversational)
- Heavy infra requirement (Postgres + Qdrant + Neo4j + Redis)
- Cron-triggered, not event-triggered
- gpt-4o-mini end-to-end — would expect score changes with stronger models

## Open questions / followups

- What's the cost per LoCoMo conversation? 5-level consolidation is many LLM calls.
- What's the score with gpt-5 / Claude Opus instead of gpt-4o-mini?
- What happens when GEPA evolves the L1-L5 prompts? Is there headroom above 75%?
- Their L1 prompt has explicit anti-duplication; ours didn't. How much of the 12pp gap is just that?

## Code

Cloned at `external/timem/`. Key files:
- `timem/memory/l{1,2,3,4,5}_*.py` — TMT implementations
- `config/prompts.yaml` — L1-L5 consolidation prompts (188 lines, the actual SOTA prompts)
- `config/datasets/locomo/*.yaml` — LoCoMo reproduction config (model = gpt-4o-mini)
- `experiments/datasets/locomo/{01,02,03}_*.py` — generation → retrieval → eval pipeline
- `services/memory_generation_service.py` — orchestrates the cron-style backfill

To reproduce 75.30%: docker-compose up the Postgres/Qdrant/Neo4j/Redis stack, set OPENAI_API_KEY, run the 3 scripts in order.

## Abstract (verbatim, for reference)

> Long-horizon conversational agents have to manage ever-growing interaction histories that quickly exceed the finite context windows of large language models (LLMs). Existing memory frameworks provide limited support for temporally structured information across hierarchical levels, often leading to fragmented memories and unstable long-horizon personalization. We present TiMem, a temporal–hierarchical memory framework that organizes conversations through a Temporal Memory Tree (TMT), enabling systematic memory consolidation from raw conversational observations to progressively abstracted persona representations.

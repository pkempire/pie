# CoALA: Cognitive Architectures for Language Agents

## Quick read

The theoretical framework that names the memory types every later paper assumes. Working memory (active context), episodic (past events), semantic (factual knowledge), procedural (how-to). Models agents as combining LLM-as-reasoner + modular memory + structured action space. TMLR 2023. The companion awesome-language-agents repo (Shunyu Yao) organizes the field by these categories.

## Why it matters to us

Foundational vocabulary. When Auto-Dreamer says "typed memory bank with semantic and procedural entries" — that's CoALA's framing. When TiMem talks about hierarchical consolidation — that's working → episodic → semantic flow in CoALA terms. We should use this taxonomy in our wiki's concept pages so cross-paper comparisons are coherent.

## Method in one paragraph

Three components: memory (4 types), action space (unified ops on internal memory + external env), decision-making (LLM reasoner cycle). Memory types map to neuroscience analogs: working = prefrontal scratchpad, episodic = hippocampal events, semantic = neocortical facts, procedural = striatal skills. The action space treats `retrieve_from_memory` the same way as `call_api` — both are tool calls with side effects.

## Why this isn't competition

It's theory. No benchmark. Foundational framing for the field.

## Abstract (verbatim, for reference)

> Recent efforts have augmented large language models (LLMs) with external resources or internal control flows for tasks requiring grounding or reasoning, leading to a new class of language agents. We propose Cognitive Architectures for Language Agents (CoALA). CoALA describes a language agent with modular memory components, a structured action space to interact with internal memory and external environments, and a generalized decision-making process to choose actions.

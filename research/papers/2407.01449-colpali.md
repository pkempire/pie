# ColPali: Efficient Document Retrieval with Vision Language Models

## Quick read

Skips OCR + chunking entirely. Embeds page IMAGES via a VLM (PaliGemma-3B), uses ColBERT-style late-interaction matching at the patch level. Wins big on visually-rich documents (PDFs with tables, charts, layouts). ICLR 2025. ColQwen2 is the larger variant. Released as open models + benchmark (ViDoRe) under permissive licenses.

## Why it matters to us

The user asked about multimodal memory. ColPali is the right retrieval primitive for that case — if a memory entry includes a screenshot, a chart, or a PDF page, ColPali retrieves over the image directly without the lossy OCR step. For purely conversational memory it's overkill; for research-project memory that includes papers and figures, it's exactly the tool.

## Method in one paragraph

Each document page → image → VLM forward pass → patch-level embeddings (multi-vector representation per page). Query → text → query token embeddings. Retrieval = max-sim per query token against all page patches (the ColBERT late-interaction trick, but visual). Training via contrastive loss on (page, relevant_query) pairs.

## Results in numbers

Wins on ViDoRe across multiple domains. Specific numbers in their table; comparison is to modern pipelines (PyMuPDF + chunking + BGE-large) which they beat by large margins on visual-heavy domains.

## When to reach for it

- Memory contains research papers (figures matter)
- Memory contains screenshots (UI state, dashboards)
- Memory contains PDFs with tables/charts
- Anything where OCR loses structure

## When not to

- Pure conversational text (overkill, dense + BM25 is enough)
- Code (different problem)
- Audio/video (different modality entirely)

## Abstract (verbatim, for reference)

> Documents are visually rich structures that convey information through text, but also figures, page layouts, tables, or even fonts. We release ColPali, a Vision Language Model trained to produce high-quality multi-vector embeddings from images of document pages. Combined with a late interaction matching mechanism, ColPali largely outperforms modern document retrieval pipelines while being drastically simpler, faster and end-to-end trainable.
